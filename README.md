# 🎭 Real Time Emotion Detection using Deep Learning

This project performs **real time facial emotion detection** using a webcam and a trained deep learning model.
It classifies facial expressions into:

- 😄 Happy
- 😢 Sad
- 😐 Neutral
- 😲 Surprised
- 😠 Angry

---

## 📌 Features
- Real-time emotion prediction using webcam.
- CNN-based trained model.
- Face detection using Haar Cascade.
- Easy-to-run Jupyter notebooks.

---

## 🧠 Technologies Used
- Python
- TensorFlow
-  Keras
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook

---

## 📂 Project Structure
- Dataset/ Emotion image datasets
- Models/ Trained .h5 model
- Notebooks/ Training & testing notebooks
- Haarcascade/ Face detection XML
- Src/ Real-time detection script

---

## 📊 Model Training
- Model training and preprocessing steps are available in:
